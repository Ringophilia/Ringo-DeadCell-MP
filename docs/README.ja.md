## 機能

- 同じラン内で各自が自分のキャラクターを操作し、敵・死亡・ドロップが同期します
- メインメニューの **マルチプレイ** からロビーへ。フレンドや公開ルームの一覧、作成、参加、管理ができます
- 扉を押すとその場で仲間を待ち、いつでもキャンセル可能。全員が同じ扉にそろったときだけ一緒に次のレベルへ進みます
- 倒れるとほかの仲間が30秒以内に助け起こせます。待っている間、カメラは仲間の1人を追います
- 仲間それぞれの頭上に名前を表示。あなたも同じ衣装をアンロックしていれば、仲間は自分の衣装で表示されます
- 敵の体力は1人増えるごとに上昇。床の装備は共有、巻物・セル・ゴールドは各自のもの
- 全員のうち最も低い進行度でレベルを生成し、セーブ済みのアンロックは書き換えません
- デイリーチャレンジとボスラッシュ：ホストが始めると全員がついてきます。一緒に遊んだランのスコアはランキングに送られません
- 途中参加、切断からの再接続、クラッシュ後は装備を持って元のレベルに復帰
- ロビーとすべてのメッセージはゲームの言語に従います（13言語）

## インストール

1. 全員が Steam 版『Dead Cells』v35 と [Dead Cells Core Modding](https://github.com/dead-cells-core-modding/core) 35.14.2 が必要です。
2. [Releases](https://github.com/Ringophilia/Ringo-DeadCell-MP/releases) から `RingoMP-v0.4.0.zip` をダウンロードし、`RingoMP` フォルダをゲームフォルダ内の `coremod\mods\` に入れます。
3. セーブデータをバックアップします：`Steam\userdata\<あなたのID>\588650\remote`
4. `coremod\core\host\startup\DeadCellsModding.exe` でゲームを起動します。

## 遊び方

1. メインメニューで **マルチプレイ** を選びます。
2. **ルームを作成** してから **フレンドを招待**、または一覧のルームを選んで参加します。
3. フレンドが入ったら、ホストが **新しくプレイを始める**、**セーブしたプレイを続ける**、**デイリーチャレンジを始める** のどれかを選びます。全員が自動でついてきます。ボスラッシュはゲーム内のその扉から、やはり全員で始まります。

ロビーはゲームのオプションと同じ画面です。マウスでクリックするか、キーボードやゲームパッドでほかのメニューと同じように操作できます。プレイ中もポーズメニューの **マルチプレイ** から同じロビーを開けます。サブルーム（チャレンジルーム、銀行など）の扉も出口と同じく、全員そろって出入りします。

## 既知の制限

- 最大4人。
- カスタムモードは非対応です。

不具合は [Issues](https://github.com/Ringophilia/Ringo-DeadCell-MP/issues) へ。`coremod\logs` の最新ログを添付してください。よくある問題は [Troubleshooting](TROUBLESHOOTING.md) にあります。
